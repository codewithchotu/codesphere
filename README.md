# CodeSphere 🚀

CodeSphere is a modern full-stack social media platform built for developers to connect, share ideas, create posts, and collaborate together.

## 🌟 Features

- User Authentication (Login/Register)
- JWT Authentication
- Create & View Posts
- Developer Feed
- User Profile Page
- Responsive UI
- Full-Stack Architecture
- MongoDB Database Integration
- REST API Integration
- Modern Tailwind CSS Design

---

## 🛠️ Tech Stack

### Frontend
- Next.js
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Bcrypt.js
